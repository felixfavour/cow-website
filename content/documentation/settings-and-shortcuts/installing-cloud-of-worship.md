CoW is a **Progressive Web App**. You can install it to your dock, taskbar or home screen so it opens in its own window without browser chrome.

## To install

Open `app.cloudofworship.com` in Chrome or Edge and use the install icon in the address bar (or **⋮ → Install Cloud of Worship**). On Safari and iOS, use **Share → Add to Home Screen**.

## Two installable apps

| App | Opens at | Use for |
|-----|----------|---------|
| **Cloud of Worship** | `/` | The Control Center |
| **CoW Live** | `/live` | The projection window |

Both open **fullscreen**, which is ideal for the projection machine.

## Updates

When a new version is released, CoW shows an update prompt. You can also visit `/update` and click **Update Cloud of Worship**. Because CoW is a web app, updating is instant. There's nothing to download and reinstall.

::callout{type="tip"}
See what's changed in each release on the [changelog](/changelog).
::

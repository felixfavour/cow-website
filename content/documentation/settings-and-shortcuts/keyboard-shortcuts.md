Open the full reference sheet any time by pressing **`?`**, **Cmd/Ctrl + H**, or via the **Shortcuts & Hotkeys** quick action. CoW groups shortcuts the same way in-app, and the tables below match that grouping.

*On Windows and Linux, **Cmd** ("Mod") is **Ctrl**.*

## General

| Shortcut | Action |
|----------|--------|
| **Cmd/Ctrl + K** | Search actions, songs, scriptures, and anything else |
| **`/`** | Jump to the quick actions search |
| **`?`** | Open the shortcuts sheet |
| **Cmd/Ctrl + Shift + S** | Open the schedules list |
| **Cmd/Ctrl + ,** | Open app settings |
| **Cmd/Ctrl + P** | Promote the slide you're previewing to the live display |
| **Cmd/Ctrl + Z** | Undo the previous action |
| **Cmd/Ctrl + Y** | Redo the previous action |
| **Cmd/Ctrl + +** | Zoom in / increase display size |
| **Cmd/Ctrl + −** | Zoom out / decrease display size |

## Slide schedule

| Shortcut | Action |
|----------|--------|
| **↓** | Send the next slide in the schedule live |
| **↑** | Send the previous slide in the schedule live |
| **Cmd/Ctrl + 1…9** | Send that numbered slide live |
| **Cmd/Ctrl + 0** | Send the last slide in the schedule live |
| **B** | Blank the live output |

## Live and stage display

*While the Live Display or Stage Display window itself has focus.*

| Shortcut | Action |
|----------|--------|
| **F** | Toggle fullscreen |
| **→** | Go to the next verse (scriptures, songs, hymns) |
| **←** | Go to the previous verse (scriptures, songs, hymns) |

## Slide styling and media

*While a slide is selected in Preview and Edit Content.*

| Shortcut | Action |
|----------|--------|
| **Cmd/Ctrl + Shift + >** | Increase font size |
| **Cmd/Ctrl + Shift + <** | Decrease font size |
| **Cmd/Ctrl + Shift + U** | Uppercase the slide text |
| **Cmd/Ctrl + Shift + K** | Toggle the line background behind the text |
| **M** | Mute / unmute the media on this slide |
| **Space** | Play / pause the media on this slide |

::callout{type="tip"}
Formatting shortcuts (bold, alignment) work the same whether you're in a text slide's rich-text editor or using the slide toolbar directly: **Cmd/Ctrl + B** for bold, and the usual alignment chords.
::

Already have a sermon deck, an order of service or a set of announcements designed somewhere else? **Import Slides from PDF** brings it into Cloud of Worship (CoW) as a **presentation slide**, with every page of the PDF ready to show. It's free on every plan.

## Export your deck as a PDF first

CoW imports PDFs from any app. Export or download your deck as a PDF from:

- **PowerPoint**: File → Export → PDF (or Save As → PDF).
- **Google Slides**: File → Download → PDF document.
- **Canva**: Share → Download → PDF Standard.
- **Keynote**: File → Export To → PDF.

## Import the PDF

1. In the [Quick Actions Pane](/docs/control-center/quick-actions-pane), click **Import Slides from PDF** (or press **Cmd/Ctrl + K** and search for it).
2. Drag your PDF onto **Upload a File or Drag & Drop here**, or click to browse. The maximum file size is **50 MB**.
3. Click **Create slides**. CoW reads the PDF, renders each page, and adds a single presentation slide to your schedule holding all the pages.

Pages are converted to JPEG images of up to 1920 pixels across, so even large, photo-heavy pages upload quickly. If a page still fails to upload, CoW keeps it on your device and retries. See [Some pages didn't upload](/docs/troubleshooting/media-and-transcription-problems#some-pages-didnt-upload).

## Present the pages

Select the presentation slide and put it on screen like any other slide (see [Promoting slides](/docs/going-live/promoting-slides)). Then move through the pages:

- Press **→** for the next page and **←** for the previous one.
- Or use the **Previous page** and **Next page** buttons in the editor, which also show the current page number (for example *3 / 12*).
- Or click a page thumbnail to jump straight to it.

## Recent Slides

::callout{type="tip" title="Open it again"}
CoW remembers decks you've already imported **on this device** under **Recent Slides**, so you can reuse a deck for a repeating series without uploading it again. This list is local to the device you imported on, not synced to your church workspace.
::

## Tips for decks that look good on a projector

- Design at **16:9** so the pages fill the screen without black bars.
- Use large text. A page that reads well on a laptop can be hard to read from the back of the hall.
- Animations and videos inside the deck don't carry over to a PDF. Add videos separately with [Add Media](/docs/building-your-service/adding-media).
- For text you'll want to change week to week, a [text slide](/docs/building-your-service/text-slides) is easier to edit than a re-imported PDF.

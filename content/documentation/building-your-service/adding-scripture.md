## Display a reference

1. Click **Display Bible**.
2. Type a reference into **Search scriptures**: `John 3:16`, `Matt 28:19`.
3. Select the verse. It's added to the schedule and opens in the editor.

Not opened any scripture yet? The panel offers an **Open Genesis 1** starting point.

## Search by phrase

Use **Search Whole Bible** when you remember a phrase but not the reference.

## Change the translation

Change the default translation in **Settings → Bible Version Settings**. You can also save translations for [offline use](/docs/settings-and-shortcuts/offline-use).

::callout{type="tip" title="Step through verses"}
With a Bible slide selected, **←** and **→** step through verses.
::

::callout{type="tip" title="Shorthand references work"}
In the verse switcher (in the slide editor), you can abbreviate the book and use spaces instead of a colon. Type `mat 28 19` and press Enter to jump straight to Matthew 28:19.
::

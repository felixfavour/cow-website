*Teams feature.* Quick Actions has two countdown destinations. Use **Live Display** when the congregation should see the timer, or **Stage Display** when only the band and speaker need it.

## Countdown slide for the congregation

1. Open **Add Countdown Timer** in Quick Actions and choose **Live Display**.
2. Pick a **Countdown duration**, or set the minutes and seconds precisely.
3. Optionally add text above the countdown.
4. Click **Create countdown slide**. The slide is added to the schedule, ready to take live.

When that slide is live, the Stage Display mirrors its remaining time unless a private stage countdown is active.

## Private countdown for the stage

1. On the computer running the Stage Display, search Quick Actions for **Stage Display Countdown**. This opens the same form on its **Stage Display** tab.
2. Set the duration and, if useful, add text beneath the countdown.
3. Click **Start stage countdown**. The timer starts on the Stage Display only. It does not create a slide or change the live output.

For a faster start, type *5 min countdown* into Quick Actions and select **Start 5 minutes countdown on stage display**. The same search also offers a live countdown action, so check the destination before selecting one.

The Stage Display has start, pause and reset buttons for its private countdown. Search **Clear Stage Countdown** when you want the service stopwatch back. If the stopwatch was running, it keeps its elapsed time underneath the countdown. See [Stage Display](/docs/going-live/stage-display) for the panel's display order and controls.

Stage clock commands work from the presentation computer. The phone's Quick Actions can still create a countdown slide for the live output, but they do not control the Stage Display clock.

::callout{type="tip"}
Need the current time instead? **Add Time Slide** displays the time of day. Like countdowns, it is a Teams feature.
::

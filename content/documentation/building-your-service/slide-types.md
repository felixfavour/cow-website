| Type | Badge | Created by |
|------|-------|-----------|
| **Bible** | Bible | Display Bible / Search Whole Bible / Transcribe Sermon |
| **Song** | Song | Search song lyrics / Add Song / My Library |
| **Song Setlist** | Setlist | Song Setlist |
| **Hymn** | Hymn | Display Hymns |
| **Text** | Text | Create Text Slide |
| **Media** | Media | Add Media / YouTube / Vimeo |
| **Countdown** | — | Add Countdown Timer |
| **Presentation** | — | Import Slides from PDF |

## Overlays

Any slide can also be flagged as an **overlay** (via **⋮ → Duplicate as Overlay**), which layers it over the live slide rather than replacing it. See [Alerts & overlays](/docs/going-live/alerts-and-overlays).

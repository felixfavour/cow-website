Select a slide in the Preview and Edit Content Pane:

![Slide editor](/images/docs/03-slide-editor.webp)

| Control | What it does |
|---------|--------------|
| **Slide title and type badge** | Confirms what you're editing (for example "Hymn 61 · Hymn") |
| **◀ Verse ▶** | Step through verses or stanzas |
| **Font dropdown** | Typeface for this slide |
| **− 90 +** | Font size percentage |
| **Lines** | Lines of content per slide |
| **Background** | Opens the background panel. See [Slide backgrounds](/docs/building-your-service/slide-backgrounds) |
| **Go Live** | Promote this exact slide immediately |

Style changes here apply to **this slide only**. To change how *future* slides look, use **Settings → Slide Settings**.

::callout{type="important" title="You can edit a slide while it is live"}
Changes appear on the Live Display as you make them.
::

## Styling shortcuts

While a slide is selected:

| Shortcut | Action |
|----------|--------|
| **Cmd/Ctrl + Shift + >** | Increase font size |
| **Cmd/Ctrl + Shift + <** | Decrease font size |
| **Cmd/Ctrl + Shift + U** | Uppercase the slide text |
| **Cmd/Ctrl + Shift + K** | Toggle the line background behind the text |

The full list is in [Keyboard shortcuts](/docs/settings-and-shortcuts/keyboard-shortcuts).

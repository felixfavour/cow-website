A **schedule** is the ordered set of slides for one service or event.

## Creating a schedule

Click the **⌄** next to the schedule name in the top bar:

![Create a schedule dialog](/images/docs/01-schedule-picker.webp)

| Option | Use it when |
|--------|-------------|
| **Start from blank** | You'll build the running order yourself |
| **Regular Sunday** | Standard weekly service skeleton |
| **Communion Service** | Communion running order |
| **Christmas Schedule** | Seasonal template |
| **Recent Schedules** | Jump back into something you built before. **See all** shows the full list |

Each row shows who created it and how long ago.

## Switching, renaming and deleting

- **Switch:** open the dialog and click any schedule.
- **Rename:** click the schedule name in the top bar.
- **Per-schedule actions:** the **⋮** on each row.

::callout{type="important" title="Switching schedules clears the live projection"}
This is deliberate, so a slide from a previous service can't linger on screen. Promote a slide from the new schedule when ready.
::

::callout{type="tip"}
**Cmd/Ctrl + Shift + S** opens the schedules list from anywhere.
::

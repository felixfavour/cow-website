Text slides are for anything that isn't a song, a hymn or a Bible verse: announcements, a welcome message, sermon points, giving details, event dates or a prayer focus. They're free on every plan.

![Rich text editor](/images/docs/09-create-text-slide.webp)

## Create a text slide

1. In the [Quick Actions Pane](/docs/control-center/quick-actions-pane), click **Create Text Slide** (or press **Cmd/Ctrl + K** and search for it).
2. The slide is added to your schedule and opens in the [Preview and Edit Content Pane](/docs/control-center/preview-and-edit-pane).
3. Type your text straight onto the slide. Changes save as you go.

## The text toolbar

When a text slide is selected, the toolbar above it shows:

| Control | What it does |
|---------|--------------|
| **Font size** (− / +) | Steps the text size up or down, shown as a percentage |
| **Bold**, **Italic**, **Strikethrough** | Emphasis for a word or line |
| **Normal text** | Turns a heading back into body text |
| **Bullet list**, **Numbered list** | Sermon points, steps or a list of events |
| **Align left / centre / right** | Line up the selected text |
| **Font** | Pick a typeface for the selection |
| **Text colour** | Recolour words, for example to highlight a key phrase |
| **Quote** | Set off a quotation |
| **Code block** | Monospaced text, handy for Wi-Fi details or a giving reference |

## Keyboard shortcuts in the editor

| Shortcut | Action |
|----------|--------|
| **Cmd/Ctrl + B** / **I** | Bold / italic |
| **Cmd/Ctrl + Shift + X** | Strikethrough |
| **Cmd/Ctrl + Alt + 1 / 2 / 3** | Heading 1, 2 or 3 |
| **Cmd/Ctrl + Alt + 0** | Normal text |
| **Cmd/Ctrl + Shift + 8** / **7** | Bullet list / numbered list |
| **Cmd/Ctrl + Shift + L / E / R** | Align left / centre / right |
| **Cmd/Ctrl + Shift + B** | Quote |
| **Cmd/Ctrl + Alt + C** | Code block |
| **Cmd/Ctrl + Shift + >** / **<** | Increase / decrease font size |

The full list is on the [Keyboard shortcuts](/docs/settings-and-shortcuts/keyboard-shortcuts) page.

## Make it readable from the back row

- Keep each slide to one idea. Several short slides read better than one crowded one.
- Use a heading for the main point and normal text for the detail.
- Put the slide on a calm [background](/docs/building-your-service/slide-backgrounds), and lower the background's **Brightness** if the text gets lost.

## Show a text slide on top of another slide

A text slide using the full-text or heading-and-subtitle layout can be turned into an overlay with **⋮ → Duplicate as Overlay**, so it sits over whatever is live instead of replacing it. See [Alerts & overlays](/docs/going-live/alerts-and-overlays#overlays-teams).

::callout{type="tip" title="Reuse it every week"}
Announcements that repeat, such as the welcome or giving slide, can be saved to [My Library](/docs/building-your-service/my-library) so you don't retype them for every schedule.
::

![Rich text editor](/images/docs/09-create-text-slide.webp)

**Create Text Slide** opens a rich-text editor with a floating toolbar: a **font size** selector, **B**, *I*, strikethrough, **H1 / H2 / H3**, paragraph, bulleted and numbered lists, and alignment.

::callout{type="tip"}
Press **`/`** inside the editor for a quick-insert command menu.
::

Formatting shortcuts (bold, alignment) work the same whether you're in a text slide's rich-text editor or using the slide toolbar directly: **Cmd/Ctrl + B** for bold, and the usual alignment chords.

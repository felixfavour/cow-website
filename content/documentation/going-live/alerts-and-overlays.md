## Alerts (Teams)

![Alert configuration](/images/docs/12-add-banner-alert.webp)

Alerts put a message on screen **without disturbing the slide underneath**, ideal for "Kids pickup for the Johnson family" mid-sermon.

1. Click **Add Banners/Alert**.
2. Pick a **colour**.
3. Choose an **Alert position** (for example Bottom).
4. Type **your alert content**.
5. Adjust the scroll **Speed** slider (Slow ↔ Fast).
6. Click **Send alert to LIVE**.

Clear it with **Remove Alert**. Set how many alerts are retained via **Settings → Other Settings → Default alert limit**.

## Overlays (Teams)

An **overlay** renders *on top of* the current live slide instead of replacing it. Think lower-thirds. Create one via a slide's **⋮ → Duplicate as Overlay**.

Configure **Position**, **Size**, and an optional **Decorative overlay** in **Settings → Overlay Settings**.

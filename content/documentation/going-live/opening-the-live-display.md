Click **Go Live** in the Slide Schedule Pane header. It opens a small menu:

| Option | What it does |
|--------|--------------|
| **Open Live Window** | *"Opens another browser window with live display"*. Drag this to your projector |
| **Copy livestream URL** | *"Copy link for OBS, VMix or similar software"*. Teams only, see [Livestream output](/docs/going-live/livestream-output-obs-vmix) |

::callout{type="important" title="Go Live opens the window, not a slide"}
**Go Live** opens the output *window*. It does not by itself put a slide on screen. Once the window is open, the button becomes **End Live Session**. To show something, [promote a slide](/docs/going-live/promoting-slides).
::

![Live projection output](/images/docs/14-live-projection.webp)

## Going fullscreen

A banner reads *"Double click the display below to toggle full screen and remove this banner."* Do exactly that, or press **F** with the live window focused.

::callout{type="tip" title="Skip this step every week"}
Turn on **Settings → Display Settings → Open in fullscreen mode** so the live window always opens fullscreen.
::

## Keeping the live window alive

By default the live window is independent of the Control Center tab. If **Settings → Display Settings → "Close live window when this tab is closed"** is on, closing the Control Center also closes the projection. Leave it **off** if you want the projection to survive a Control Center reload. See [Multi-screen setup](/docs/going-live/multi-screen-setup).
